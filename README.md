## Authentication added

- `/login` supports the existing demo accounts (password: `demo123`).
- `/register` creates a new account and automatically signs the user in.
- Registered accounts are stored in browser `localStorage` under `cropshield_registered_users`.
- Passwords are stored as SHA-256 hashes rather than plain text.
- Role-based redirects send users to the correct dashboard.
- Existing dashboard layouts continue to protect their routes on the client.

> **Important:** This authentication is suitable for a local/SIH prototype only. For production deployment, move users/passwords/session handling to a real server-side identity provider/database (for example, Auth.js, Supabase Auth, Firebase Auth, or your own backend).
